The server rebuilds the pen's actual style when the owner rebirths. Current models also include independent decoration props.

### Source folders within the local Roblox project

| Source | What is in it | How it was matched |
| --- | --- | --- |
| `Animal_Rig_Lab_20261028/export/` | A rigged animated GLB for each of the 72 current IDs, alongside rig and clip data. | All 72 current `WR.Species` IDs have a same-ID `WRAnimals` template and a same-ID local GLB. The project's import notes identify this Animal Rig Lab pack. |
| `Animal_Rig_Lab_20261028/verification/rig/` | The 72 original three-view model pictures used in the next six chapters. | Each image is keyed by its current model ID, including the renamed Enchanted pets. The pictures show the source rigs before in-game appearances, lighting, pose overrides and sizing. |
| `wild_ranch/sap_uploads_20261116/` | Local melee GLBs, decoration and shop revisions and owner-provided icons. | Named décor exports correspond to the twelve live template slots. Later uploads may use another local revision of a given GLB. |
| `wild_ranch_build/assets/` and `wild_ranch/models/` | Terrain textures, biome meshes, hub works, enclosure art and source packs. | Each of the six biome namespaces is present in the current runtime library, alongside hub and enclosure packs. |
| `wild_ranch/gun_models/` and `wild_ranch/All_15_Revised_Tranquilizer_Images_V11/` | Gun models and design images. | Version 260 uses 15 in-place gun models in `WRGuns` and `WRGunShow`. Some local reference filenames use old weapon names. Exact geometry revisions are not confirmed by filenames. |
| `wild_ranch_build/docs/evidence/` and `wild_ranch/playtest_release_20261031/` | The original screenshots used in the visual archive. | Matching project archive and in-game scene contents. Old images are labeled as earlier builds. |

The checked model IDs and picture names establish correspondence with the active roster. File membership by name does not establish that an uploaded Roblox mesh is byte-for-byte identical to every local export. Whether a particular asset resolves for a hosted player was outside this review.
